The code

Paste it where you want the box. WordPress: a Custom HTML block. Wix: Embed Code. Squarespace: a Code block. If your site strips the script line, the box still works at a set height.

What it does and doesn't do

  • It changes by itself every morning, from the same checked plans as this site. Nothing to update.
  • Each line goes to the full plan on Triangle Tots, in a new tab.
  • It sets no cookies and loads no ads or trackers on your page. We count that the box was shown and which site it was on, the same way we count our own pages. Privacy
  • Want it to show something else, or help putting it on your site? Email support@tottoolbox.com.
